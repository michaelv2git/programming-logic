# Aritmeticos: sirven para hacer operaciones básicas
* `+` **Suma:** suma dos valores.
* `-` **Resta:** resta el valor mayor con una cantidad menor.
* `*` **Multiplicación:** suma x veces de lo que indica otro número.
* `/` **División:** partir en una cantidad específica otro número.
* `//` **División entera:** sirve también para dividir, pero, la diferencia, es que el resultado siempre descartará los decimales.
* `%` **Módulo:** sirve para obtener el residuo o resto de una división entre dos números enteros o en algunos casos floats.
* `**` **Potencia:** sirve para multiplicar x veces su base tanto como lo indique su exponente.

# Lógicos: and, or, not
* Sirve para conectar expresiones verdaderas o falsas con el fin de obtener un valor lógico único.

# Comparación: ==, !=, >, <, >=, <=
* Se utiliza para compara dos valores. Estos siempre nos devolveran un valor lógico o booleano.

# Asignación: =, +=, -=, *=, /=, //=, %=, **=
* Se utilizan para hacer las mismas operaciones básicas, pero estas nos permiten ahorrar código y tener un espacio mas limpio.

# Identidad: is, is not
* Sirve para comparar y ver si un objeto es igual o no a otro objeto.

# Pertenencia: in, not in
* Es para identificar si un valor se encuentra dentro de una secuencia o colección, ya sea una lista o cadena de texto.

# Bits: &, |, ^, ~, <<, >>
* Nos permite manipular los dígitos binarios, que es el 1 y 0, de los números enteros.
